# RAG OCR Evaluation

This project is an evaluation pipeline designed to assess the performance of Retrieval-Augmented Generation (RAG) systems on documents processed via Optical Character Recognition (OCR). It extracts text from PDF documents using PaddleOCR, indexes the extracted text into a local vector database (ChromaDB), and evaluates the quality of responses generated by a local LLM (via Ollama) based on the retrieved context.

## Features

- **Robust OCR Extraction**: Uses `PaddleOCR` and `PyMuPDF` to accurately extract text from PDF documents by rendering pages as high-resolution images.
- **Local Vector Database**: Utilizes `ChromaDB` for efficient, persistent storage and retrieval of document embeddings.
- **Local LLM Inference**: Leverages `Ollama` (specifically configured for `llama3.2`) for generating answers from retrieved document contexts, ensuring data privacy and local execution.
- **Comprehensive Metrics**: Automatically computes evaluation metrics (Faithfulness, Answer Relevancy, Composite Score) to quantify the RAG system's performance.

## Prerequisites

Before running the project, ensure you have the following installed:

- Python 3.8+
- [Ollama](https://ollama.com/) installed and running locally with the `llama3.2` model pulled (`ollama run llama3.2`).

## Installation

1. Clone the repository or navigate to the project directory:
   ```bash
   cd rag-ocr-eval
   ```

2. Install the required Python dependencies:
   ```bash
   pip install paddleocr paddlepaddle pymupdf chromadb numpy ollama
   ```
   *(Note: You may need to install the appropriate version of `paddlepaddle` based on your system and whether you are using CPU/GPU).*

## Usage

### 1. Extract Text from PDF

To extract text from a PDF and save it as a structured JSON file, you can run the OCR extractor:

```bash
python ocr_extractor.py
```

*Make sure to update the `pdf_filename` path inside `ocr_extractor.py` to point to your target PDF file.*

### 2. Run the Evaluation Pipeline

Once you have the extracted JSON file, you can run the evaluation pipeline. The pipeline will:
1. Index the JSON data into ChromaDB.
2. Run predefined queries against the database.
3. Generate answers using Ollama.
4. Evaluate the answers and output a CSV report.

```bash
python main.py
```

*Ensure the `OCR_JSON_PATH` in `main.py` points to the JSON file generated in Step 1.*

## Project Structure

- `main.py`: The core RAG evaluation pipeline script.
- `ocr_extractor.py`: Extracts text and bounding boxes from PDFs using PaddleOCR.
- `pdf_extractor.py`: Utility script for standard PDF text extraction.
- `metrics.py`: Contains functions for computing RAG evaluation metrics.
- `chroma_db/`: Directory for persistent vector database storage.
- `pdfs/`: Directory containing source PDF files and extracted JSON data.
- `results/`: Directory where the evaluation output CSV files are saved.
- `test.ipynb`: Jupyter notebook for testing and experimentation.
